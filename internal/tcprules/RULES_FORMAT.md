# Текстовый формат правил для tcprules

## 1. **Базовая структура**
```
адрес:действие[,переменные]
```

## 2. **Формат адреса**
- **Точный IP**: `192.168.1.100`
- **Подсеть**: `192.168.1.` (соответствует подсети 192.168.1.0/24)
- **Диапазон**: `192.168.1.10-20` (генерирует 192.168.1.10 - 192.168.1.20)
- **Множественные диапазоны**: `10.1-2.0-1.100` (генерирует 4 адреса)
- **Специальные** (не обрабатывают диапазоны):
  - `user@=host`
  - `key=value` 
  - `=hostname`
- **Пустой адрес**: `:` (правило по умолчанию)

## 3. **Действия**
- `deny` - запретить соединение
- `allow` - разрешить соединение

## 4. **Переменные окружения** (только для `allow`)
```
,ИМЯ="значение"
```
- **Имя**: буквы/цифры/`_`, начинается с буквы или `_`
- **Значение**: в парных разделителях:
  - `"value"` - двойные кавычки
  - `'value'` - одинарные кавычки  
  - `/value/` - слеши
  - `|value|` - вертикальные черты
  - и т.д. - любой парный символ

## 5. **Синтаксические правила**
- **Комментарии**: строки начинающиеся с `#`
- **Пробелы**: игнорируются в начале/конце строки
- **Разделители**: `:` разделяет адрес и правило, `,` разделяет переменные

## 6. **Примеры валидных правил**
```
# Запретить конкретный IP
192.168.1.100:deny

# Запретить диапазон
192.168.1.10-20:deny

# Разрешить подсеть с переменными
192.168.1.:allow,RELAYCLIENT="",TCPLOCALHOST="example.com"

# Правило по умолчанию - запретить всё
:deny

# Разрешить с кастомным разделителем
:allow,PATH=|/usr/local/bin/|

# Специальные адреса
user@192.168.1.1:allow
=example.com:deny
key=value:allow

# Множественные переменные
:allow,DB_HOST="db1",DB_PORT="5432",APP_ENV="production"
```

## 7. **НЕвалидные примеры**
```
192.168.1.100 deny           # отсутствует :
allow,KEY=value              # отсутствует адрес и :
192.168.300.1:deny           # невалидный IP
:allow,123KEY="value"        # имя начинается с цифры
:allow,KEY=value             # нет кавычек
:allow,KEY="value            # незакрытая кавычка
:allow,PATH=/usr/local/      # разделитель внутри значения
```
